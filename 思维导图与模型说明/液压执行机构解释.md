# 液压执行机构：阀控、电机与压力状态更新

## 一句话总结

这是一个每 0.01 s 更新一次的主缸助力电机液压模型：先把减速度指令换算成轮缸压力目标，再通过进液阀、释放阀和电机转速控制主缸压力，主缸压力推动轮缸压力变化，最后把轮缸压力换算成实际减速度。

## 1. 四个会“记住过去”的状态量

| 状态 | 含义 | 单位 | 为什么需要它 |
|---|---|---|---|
| `p_wc` | 轮缸压力 | 模型内部压力单位，未声明 | 代表车轮制动压力。它建立和释放都需要时间，决定输出的实际减速度。 |
| `p_mc` | 主缸压力 | 模型内部压力单位，未声明 | 代表助力主缸可提供的压力。它需要电机建压，也会向轮缸供液。 |
| `n_m` | 助力电机转速 | rpm | 电机不能瞬间达到指令转速；保存当前转速才能表现加速和减速的滞后。 |
| `e_f` | 滤波后的压力误差 | 模型内部压力单位，未声明 | 平滑目标与轮缸压力的差值，减少压力在目标附近轻微波动时阀门频繁开关。 |

它们不是四个互不相关的“结果数字”，而是模型对液压过程的记忆：电机有转速惯性，主缸在建压，轮缸在充液或卸压，阀控误差也经过滤波。模型每步算出新的 `[p_wc, p_mc, n_m, e_f]`，通过 `StateDelay` 延迟一拍后作为下一步的当前状态。

## 2. 参数逐个看

模型中 `ActParams` 是一个按固定顺序排列的 20 项向量；以下当前值按 `.slx` 参数块和 `plant_step` 内的索引对应。压力相关量的单位没有在模型中声明，所以不擅自写成 bar 或 MPa。

| 参数 / 信号 | 当前值 | 单位 | 通俗含义与作用 |
|---|---:|---|---|
| `a_cmd` | 随 PID 输出 | m/s² | PID 给执行机构的减速度指令。先被限制在 `0` 到 `a_brake`，再换成压力目标。 |
| `a_brake` | 约 `6.86` | m/s² | 当前可用减速度上限；限制命令和最终 `a_act`，也就是模型中的制动能力上限。 |
| `k_dec` | `0.08` | (m/s²)/压力单位 | 压力与减速度的换算系数；压力乘它得到减速度。越大，同样压力对应的减速度越大。 |
| `p_ref` | 随 `a_cmd` 变化 | 压力单位 | 目标轮缸压力，等于限幅后的减速度指令除以 `k_dec`。命令越大，目标压力越高。 |
| `e` | 随状态变化 | 压力单位 | 未滤波误差 `p_ref-p_wc`。正值说明轮缸压力低于目标，负值说明压力高于目标。 |
| `e_f` / `e_f_new` | 随状态变化 | 压力单位 | 滤波前保存值 / 本步滤波后的误差，供阀门判断；滤波让阀控反应不那么敏感。 |
| `tau_e` | `0.02` | s | 压力误差滤波时间常数。越大，滤波更慢、阀门动作更平缓；越小，跟随更快。 |
| `e_db` | `0.3` | 压力单位 | 阀门死区宽度。误差落在 `-e_db` 到 `e_db` 内时两阀都关。死区越大，阀门越不容易因小误差动作。 |
| `Kv_ap` | `0.01` | 1/压力单位 | 进液阀开度增益。误差为正并超过死区时，它决定进液阀开多大，最终被限制在 0 到 1。 |
| `Kv_rel` | `0.02` | 1/压力单位 | 释放阀开度增益。误差为负且超过死区时，它决定释放阀开多大，同样限制在 0 到 1。 |
| `u_ap` | `0` 到 `1` | 开度比例 | 进液阀开度；0 为关，1 为全开。控制主缸向轮缸供液。 |
| `u_rl` | `0` 到 `1` | 开度比例 | 释放阀开度；0 为关，1 为全开。控制轮缸卸压。 |
| `p_margin` | `15` | 压力单位 | 主缸目标相对轮缸目标多留的一点压力余量，让主缸有压力差可向轮缸供液。 |
| `kp_n` | `25` | rpm/压力单位 | 主缸压力误差到电机转速的比例增益。越大，压力不足时给出的转速要求越高（最后仍受转速上限限制）。 |
| `n_ff` | `1000` | rpm | 电机转速前馈基础量；加到转速反馈计算值上，帮助电机提前提供建压能力。 |
| `n_max` | `2500` | rpm | 电机最大转速，也限制转速指令和状态转速。 |
| `tau_m` | `0.06` | s | 电机转速响应时间常数。越大，电机追上目标转速越慢。 |
| `p_build` | `700` | 压力单位/s | 低压时的基础建压速率。越大，电机能建立主缸压力的速度越快。 |
| `p_stall` | `220` | 压力单位 | 建压效率开始降到零的堵转压力标尺。主缸压力越接近它，电机继续建压越困难。 |
| `tau_use` | `0.06` | s | 主缸向轮缸供液的时间尺度。越小，给定压力差下主缸向轮缸供液越快，也会更快消耗主缸压力。 |
| `tau_fill` | `0.04` | s | 轮缸充液时间常数。越小，进液阀打开时轮缸升压越快。 |
| `tau_rel` | `0.05` | s | 轮缸释放时间常数。越小，释放阀打开时轮缸卸压越快。 |
| `leak_mc` | `0.5` | 压力单位/s | 主缸泄漏量系数。越大，主缸压力衰减越快。 |
| `leak_wc` | `0.02` | 1/s | 轮缸泄漏系数。越大，轮缸压力在无其他作用时下降越快。 |
| `p_lp` | `1` | 压力单位 | 低压基准。泄漏、卸压项只针对高于这个基准的压力计算。 |
| `p_max` | `180` | 压力单位 | 主缸和轮缸共同使用的压力上限；状态每次更新后都限制在 0 到该上限。 |
| `Ts` | `0.01` | s | 模型离散步长，每 0.01 s 更新一次状态。 |

## 3. 按图从 ① 到 ⑧ 走一遍

### ① 输入：收到命令和上一步的状态

模型输入包含 `a_cmd`、`a_brake`、20 项 `ActParams`，以及当前的 `p_wc`、`p_mc`、`n_m`、`e_f`。后四项来自上一拍状态延迟。也就是说，同一份减速度命令在不同的当前压力、电机转速下，可能产生不同的压力变化。

### ② 参考压力与误差滤波：把“想减多少速”换成“想要多少压力”

```text
a_limited = clamp(a_cmd, 0, a_brake)
p_ref = a_limited / k_dec
e = p_ref - p_wc
e_f_new = e_f + Ts * (e - e_f) / tau_e
```

`clamp(x, low, high)` 表示把数值限制在上下界内。比如要求负减速度或超过能力上限，先分别压到 0 或 `a_brake`。随后用 `k_dec` 换算出轮缸目标压力。`e` 比较目标轮缸压力和当前轮缸压力；`e_f_new` 则是平滑后的误差。

`tau_e` 越小，滤波值越快跟上误差；越大，误差变化被抹得更平缓，但阀门动作也会更慢。`e_db` 越大，误差更容易落在两阀都关闭的范围。

### ③ 阀门判断：压力不够就进液，压力太多就释放

```text
如果 e_f_new > e_db：
    u_ap = clamp(Kv_ap * e_f_new, 0, 1)
    u_rl = 0
否则如果 e_f_new < -e_db：
    u_ap = 0
    u_rl = clamp(Kv_rel * (-e_f_new), 0, 1)
否则：
    u_ap = 0，u_rl = 0
```

- `e_f_new > e_db`：轮缸压力低于目标足够多，打开进液阀，主缸可以给轮缸充液。
- `e_f_new < -e_db`：轮缸压力高于目标足够多，打开释放阀，让轮缸卸压。
- 误差在死区内：两只阀都关闭，压力大体保持（仍可能有少量泄漏）。

同一拍不会同时打开两只阀。死区是为了避免误差在目标附近小幅上下抖动时，阀门也跟着快速开关。增大 `Kv_ap` 或 `Kv_rel`，相同误差下对应阀门开度更大，但开度仍不会超过 1。

### ④ 电机转速：根据主缸压力需要来决定电机转多快

```text
n_cmd = clamp(kp_n * (p_ref + p_margin - p_mc) + n_ff, 0, n_max)
n_new = n_m + Ts * (n_cmd - n_m) / tau_m
n_new = clamp(n_new, -n_max, n_max)
```

电机转速不是由 `a_cmd` 直接指定。模型先看主缸当前压力 `p_mc` 与目标 `p_ref + p_margin` 的差，再通过比例增益和前馈量算出转速指令。主缸压力不够时转得快些；接近目标时转速指令会下降。然后用 `tau_m` 让实际模型转速逐渐追上指令，而不是瞬间跳过去。`n_ff` 或 `kp_n` 越大，要求的转速通常越高；`n_max` 限制最高转速。

### ⑤ 建压效率：越接近堵转压力，新增压力越困难

```text
build_eff = p_build * max(0, 1 - p_mc / p_stall)
```

`p_build` 决定低压时的基础建压速度。`p_mc` 很低时，括号接近 1，建压能力较强；主缸压力逐渐接近 `p_stall` 时，括号逐渐到 0，建压效率下降；超过该压力后被 `max(0, ...)` 截为 0。`p_stall` 是模型用来表示电机/泵继续建压困难程度的压力标尺。

### ⑥ 分别算主缸和轮缸的压力变化率

主缸和轮缸是两个不同的压力节点，公式不能混成一个。按模型代码，变化率是：

```text
dp_mc = (n_new/n_max)*build_eff
        - u_ap*max(p_mc - p_wc, 0)/tau_use
        - leak_mc*sign(max(p_mc - p_lp, 0))

dp_wc = u_ap*max(p_mc - p_wc, 0)/tau_fill
        - u_rl*max(p_wc - p_lp, 0)/tau_rel
        - leak_wc*max(p_wc - p_lp, 0)
```

主缸一边由电机建压，一边向轮缸供液，还会泄漏；进液阀打开且主缸压力高于轮缸时，主缸供液项会扣掉主缸压力。轮缸一边从主缸进液，一边通过释放阀卸压，也会泄漏。

`tau_use` 小会让主缸供液项变大；`tau_fill` 小会让轮缸充压更快；`tau_rel` 小会让轮缸放压更快；`leak_mc`、`leak_wc` 大则让各自压力掉得更快。这里的公式体现的是这个教学模型的简化关系，不是完整实车液压管路方程。

### ⑦ 更新压力状态：按 0.01 秒积分，再限幅

```text
p_mc_new = clamp(p_mc + Ts * dp_mc, 0, p_max)
p_wc_new = clamp(p_wc + Ts * dp_wc, 0, p_max)
```

把本拍压力变化率乘以步长，累加到旧压力上，得到新压力。`p_max` 将主缸和轮缸压力限制在 0 到 180 的模型范围内。步长 `Ts` 越大，每次跨过的时间越长；当前模型用 0.01 s 步进。

### ⑧ 输出实际减速度和新状态

```text
a_act = clamp(k_dec * p_wc, 0, a_brake)
p_wc_out = p_wc_new
state_new = [p_wc_new, p_mc_new, n_new, e_f_new]
```

这里有一个时序细节：`a_act` 用的是**本步输入的旧 `p_wc`**，而输出的 `p_wc_out` 和状态向量用的是更新后的 `p_wc_new`。所以反馈显示的是“当前压力对应的减速度”，更新的压力留给下一拍使用。这避免 PID 与执行机构在同一拍互相即时依赖，形成代数环。状态通过 `StateDelay` 进入下一拍；模型中的 Unit Delay 初值为 `[0;0;0;0]`，采样时间 0.01 s。

## 4. 三个场景走读

### 场景一：制动命令从 0 跳到 6 m/s²

- **第 1 拍**：`a_cmd` 从 0 变成 6，先限制到 `a_brake` 范围内；由于 6 低于约 6.86，`p_ref=6/0.08=75` 个模型压力单位。
- **接下来几拍**：若当前 `p_wc` 还是低压，`e_f_new` 逐渐变正并超过 `e_db=0.3`，进液阀开，释放阀关。与此同时电机根据 `p_ref+p_margin-p_mc` 提高目标转速并逐渐加速。
- **随后**：电机建立主缸压力，主缸在有压力差时向轮缸供液，`p_wc` 上升，`a_act` 随当前轮缸压力上升。
- **接近目标时**：误差滤波值进入死区，两阀关上；压力继续受惯性和泄漏影响缓慢变化。

### 场景二：保持制动指令

- `a_cmd` 和 `p_ref` 基本不变，轮缸压力接近目标后，`e_f_new` 进入 `[-e_db,e_db]`，两阀关闭。
- 电机转速由压力目标与主缸压力差决定，通常会降低，不必持续以最大速度转。
- 两路压力不会被强行冻结：模型仍有 `leak_mc` 和 `leak_wc` 泄漏项；压力差存在时也可能继续供液。

### 场景三：松开制动，`a_cmd=0`

- `p_ref` 降到 0；轮缸仍有压力时 `e=p_ref-p_wc` 为负。
- 当滤波误差低于 `-e_db`，进液阀关闭，释放阀打开，轮缸压力下降，`a_act` 随之减小。
- 轮缸压力降到接近低压基准后，释放项减小；当压力接近 0，`a_act` 也回到 0。与此同时电机转速指令也随主缸压力需求变化并逐渐回落。

## 5. 常见误解

1. **把 `a_cmd` 当作压力。** 它是减速度指令，先经过限幅，再除以 `k_dec` 才得到目标轮缸压力 `p_ref`。
2. **把 `p_ref` 当作主缸压力。** `p_ref` 是轮缸压力目标；电机追踪的主缸目标还加了 `p_margin`，即 `p_ref+p_margin`。
3. **把 `e_f` 当作减速度误差。** 它是 `p_ref-p_wc` 的滤波结果，单位是模型压力单位。
4. **把 `u_ap` 和 `u_rl` 当压力。** 它们是进液阀、释放阀的开度比例，范围为 0 到 1。
5. **认为两只阀会同时打开。** 代码用 `if/elseif` 分支；进液、释放、死区三种情况互斥。
6. **把主缸压力 `p_mc` 和轮缸压力 `p_wc` 混为一个量。** 主缸供液到轮缸，二者之间有压力差、流量和泄漏，模型分别更新它们。
7. **认为电机转速由 `a_cmd` 直接决定。** 转速由主缸目标与当前主缸压力差、前馈项和电机响应共同决定。
8. **认为 `a_act` 使用了刚算出的新轮缸压力。** 实际用当前状态里的 `p_wc`；`p_wc_new` 保存给下一拍，避免同拍代数环。
9. **把图里的压力单位理解成 bar 或 MPa。** 模型未声明压力单位，不能据此直接换算成实车压力。
10. **认为压力更新后不会超过范围。** 每拍都会把 `p_mc_new`、`p_wc_new` 限制在 0 到 `p_max`。

## 6. 与实际模型对应

本说明对应 `AEB_v1_wzq/执行机构 主缸助力电机液压/plant_step`，参数来自相同子系统中的 `ActParams`，状态由 `StateDelay` 保存。模型每 0.01 s 更新；`StateDelay` 初值是 `[0;0;0;0]`。

我核对了 `.slx` 内的 `plant_step` 实际代码：公式与图中给出的核心流程一致。细节上，`a_act` 明确使用当前的 `p_wc`；建压效率、压力变化率、限幅和状态输出顺序均如上所述。`ActParams` 的 20 项当前值依次为：`[0.08; 1; 180; 0.04; 0.05; 0.01; 0.02; 0.3; 0.02; 0.01; 15; 2500; 0.06; 700; 220; 0.06; 25; 1000; 0.5; 0.02]`。如果图和模型之后出现参数或代码差异，应以模型实际块值和 `plant_step` 代码为准。
